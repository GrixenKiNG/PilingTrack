## Ошибки исследовательского harness, сохранённые отдельно

- Desktop: нижняя кнопка по CSS не видна; сценарий переведён на телефонный размер.
- Первая офлайн-попытка получила реальный 409: обязательный периодический TB_PILING ещё не пройден. Проверка дополнена реальным прохождением, серверный запрет не обходился.
- Для возврата на главный экран искалась кнопка «Главная», тогда как v7 называет её «Смена».
- SQL сначала ошибочно предполагал FeedbackEvent.tenantId; такой колонки нет. Проверка исправлена по схеме и публичному reportId. Поиск по внутреннему ID тоже давал ложное отсутствие журнала. Отсутствующая запись журнала не является подтверждённым дефектом.

Ни один из этих красных запусков не объявлен успешным. Их JSON/логи сохранены отдельно. Источник приложения ради теста не менялся.
