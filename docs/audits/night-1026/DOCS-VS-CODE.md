## Схема, роли, контейнеры и команды

Реальная изолированная БД:113применённых миграций,0незавершённых,84таблицы включая _prisma_migrations. CHECK chk_user_role_valid содержит ADMIN/DISPATCHER/OPERATOR/ASSISTANT/MECHANIC/FOREMAN/SAFETY_ENGINEER, ровно как Role union. В Prisma это String, не enum: контроль значений выполняет SQL CHECK. Схема/миграции не менялись. schema-facts.json содержит вывод SQL, не credentials.

Compose называет app/workers/migrate/postgres/pgbouncer/redis/redis-cache/minio; container_name отличаются от service names. URLs app/workers используют app role и PgBouncer, migrations — владельца напрямую. Наличие переменных в Compose не доказывает подключение production. prod:smoke существует, default у скрипта production — в этом задании только явный localhost.
