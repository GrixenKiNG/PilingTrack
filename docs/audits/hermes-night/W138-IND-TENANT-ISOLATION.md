- **Фоновые/воркерные пути** (`outbox-publisher.ts`, `event-handlers.ts`, `dead-letter-queue.ts`, `telemetry-ingestion-service.ts`, `services/notifications/*`) — просмотрены точечно; системные таблицы (`OutboxEvent`, `DeadLetterQueue`) по дизайну обрабатываются в разрезе организации из события.
