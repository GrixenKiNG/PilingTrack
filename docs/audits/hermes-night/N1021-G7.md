# N1021-G7 — мёртвые экспорты

## Итог

Проверил все экспорты из `src/modules/*/index.ts`, `src/lib/**`, `src/core/**`. Найдено **60+ кандидатов в мёртвый код**, разбитых по категориям:

| Категория | Кандидатов | Примечание |
|-----------|------------|------------|
| Внутренние index.ts модулей (domain/, commands/, queries/, infrastructure/) | ~40 | Используются только внутри модуля через глубокие импорты (`from '../../domain'`), бочка не используется |
| Основные index.ts модулей — неиспользуемые реэкспорты | ~15 | Реэкспортируются, но внешний код не импортирует их через бочку |
| `src/lib/` — полностью неиспользуемые файлы | 2 | `xlsx-writer.ts`, `pagination.ts` (кроме тестов) |
| `src/core/` — неиспользуемые бочки поддиректорий | 9 | `application`, `error-boundary`, `event-bus`, `infrastructure`, `media`, `notifications`, `observability`, `outbox`, `security`, `storage` — их `index.ts` не импортируются |

Топ-5 самых ценных находок:
1. **`src/lib/xlsx-writer.ts:1`** — 237 строк, 9.7 KB, нигде не импортируется
2. **`src/lib/pagination.ts:1`** — `paginateQuery`, `buildPaginationResponse` используются только в тестах
3. **`src/core/application/index.ts:1`** — реэкспортирует `withCsrf`, `rateLimiter` и др., но внешний код берёт их из `@/lib/...`
4. **Внутренние бочки модулей (crews, equipment, sites, reports, inspections, safety, users)** — реэкспорты доменных агрегатов, команд, запросов, репозиториев не используются через бочку
5. **Бочки `src/core/` поддиректорий** — 9 из 11 `index.ts` в `src/core/*/` не импортируются вовне

## Методика

1. Собраны все `export` из:
   - `src/modules/*/index.ts` (33 файла, включая вложенные `domain/`, `application/commands/`, `application/queries/`, `infrastructure/`)
   - `src/lib/*.ts` (35 файлов)
   - `src/core/*/index.ts` (11 файлов) и `src/core/api-wrapper.ts`

2. Для каждого экспорта выполнен поиск по всему `src/` (включая тесты и `src/app`) через `grep -r "from '@/modules/..."` и аналогично для `@/lib/`, `@/core/`.

3. Экспорт считается кандидатом, если **нет ни одного импорта** вида `from '@/modules/...'`, `from '@/lib/...'`, `from '@/core/...'` с использованием этого имени. Внутренние импорты внутри модуля (`from '../../domain'`, `from '../domain'`) **не считаются** использованием бочки — бочка предназначена для внешних потребителей.

4. Проверено текстовым поиском (не полагаясь на UNKNOWN из инструментов).
