## Что видит человек: сценарий за сценарием

Тексты дословно; источник — файл:строка. Список объектов собирается из трёх запросов (`/api/analytics/sites`, `/api/crews/all`, `/api/sites/all`), поэтому «успех списка» наступает только когда ответили все три.

- **409** к чтению неприменим.

### Повторы одного и того же объяснения на разные ситуации (сводка)

- Отказ по правам: баннер «Аналитика объектов недоступна (403)» (список) / «Доступ запрещён» (удаление, деактивация) / «Ошибка создания объекта» (создание) / «Ошибка сохранения» (правка) / «Ошибка добавления» (узел) / «Ошибка удаления» (узел) / полная тишина (назначение оператора) — семь разных исходов, пять из них не говорят про права.
- Обрыв сети: русское «Нет соединения с сервером.» достижимо только через `useSitesData`, а на экране видно английское «Failed to fetch» (баннер) и «Ошибка»/«Ошибка создания объекта»/«Ошибка сохранения» (тосты).
