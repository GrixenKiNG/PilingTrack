- Работающие ограничения на клиента: **нет ни одного** (0).

### Чего не хватает, чтобы продавать несколько организаций по договору без биллинга (ручное администрирование)
1. Проверки `Tenant.maxUsers` при создании пользователя (находка 1).
2. Способа приостановить/выключить организацию (проверка `Tenant.isActive`, находка 2).
3. Админского управления организациями (создание/правка, находка 3) — сейчас только сид `prisma/seed.ts:119-128`.
4. Учёта и лимитов по объектам/установкам/отчётам/фото/хранилищу (находки 4-6).
5. Привязки флагов функций к организации, а не к окружению (находка 7).
