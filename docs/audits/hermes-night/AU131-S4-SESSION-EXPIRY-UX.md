## Итог

1. При любом 401 приложение **молча выкидывает пользователя**: `authFetch` делает POST /api/auth/logout, чистит стор, а оболочка `(app)/layout` уводит на `/login` — без предупреждения и без вопроса (src/lib/api.ts:57-70 + src/app/(app)/layout.tsx:349-353).
2. **Ввод формы отчёта сохраняется частично**: черновик лежит в localStorage (`report-draft-{user}-{site}-{date}`), но последние ≤800 мс набора теряются, фото теряется, и сам черновик после повторного входа автоматически не подхватывается (use-report-form.ts:283-309, 295, 102).
3. **Наряд (ТО и наряд-допуск) и осмотр черновика не имеют вообще** — при 401 весь набранный текст пропадает (work-order-form-dialog.tsx:247-263; maintenance-request-form.tsx:99-135; run-inspection.tsx:196-213; permit-form.tsx:207-259).
4. Возврата на прерванную форму нет: после входа всегда домашний экран роли, адрес формы нигде не запоминается (login/page.tsx:13-17; routes.ts:29-40).
5. Сессия — фиксированные 12 часов без продления и без предупреждения: посреди 12-часовой смены форма умирает гарантированно, даже если человек всё время работал (session-service.ts:8, 207, 287). Найдено: **критично 0, важно 9, мелочь 8** (всего 17).

## Как это работает сейчас (механика)

Один код на всех: `authFetch` (src/lib/api.ts:29-91) перехватывает **любой** 401 — POST `/api/auth/logout` (строки 59-62), затем `usePilingStore.getState().logout()` (67-69). `logout()` обнуляет `currentUser`, `actingAs`, `selectedSiteId`, `currentPage` (src/lib/store.ts:105-113). Оболочка видит `!currentUser` и делает `router.replace('/login')` (src/app/(app)/layout.tsx:349-353). Ни тоста, ни диалога, ни попытки сохранить ввод в этом пути нет. 401 рождается в `requireAuth`: нет токена / токен невалиден / пользователь деактивирован / разошлась `sessionVersion` (src/lib/auth.ts:163-187).

Отдельно: **401 на фоновом опросе тоже выкидывает из формы.** `FeedbackCenter` смонтирован в обеих оболочках (src/app/(app)/layout.tsx:104 и 209) и опрашивает `/api/feedback/events` через `authFetch` каждые 30 c (панель открыта) / 180 c (закрыта) / 300 c (фон), плюс дёргает опрос при возврате во вкладку (src/components/piling/use-feedback-feed.ts:83, 130-151). Данные формы оператора при этом не сохраняются — их хранит только React-состояние.
