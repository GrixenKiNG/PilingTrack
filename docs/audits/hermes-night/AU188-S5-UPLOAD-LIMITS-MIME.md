## Резюме для владельца

1. Все загрузки идут не через сервер приложения, а напрямую в S3-совместимое хранилище (R2/MinIO) по presigned-ссылке; сервер проверяет файл потом, на шаге «подтвердить загрузку».
2. Шаг подтверждения — необязательный: если клиент его не вызвал, ни лимит размера, ни проверка типа по содержимому не срабатывают, а объект в бакете остаётся навсегда (уборщика нет).
3. Лимит размера задаётся переменной `MEDIA_MAX_FILE_SIZE`; при нечисловом значении он молча превращается в «без лимита» (`parseInt` → `NaN`).
4. Антивируса и любого сканирования загруженных файлов в проекте нет, при этом разрешены PDF, DOC и DOCX (переносимые макросы) — такой файл хранится и скачивается.
5. Что сделано правильно: тип проверяется по первым байтам файла, SVG/HTML не разрешены, расширение и путь объекта не берутся из имени файла (подстановка пути закрыта), есть CSRF и лимит частоты.
