1. **Поиск файлов:** `find src/components/piling -name "*.tsx" -o -name "*.ts" | xargs wc -l | sort -rn`
2. **Фильтрация:** исключены `__tests__/**`, `operator*/**`, `operator-dashboard.tsx`, `operator-v*/**`, `operator-mobile/**` (замороженные зоны по AGENTS.md §1.5).

## Не проверено

1. **E2E покрытие Playwright** для этих компонентов — не проверялось (требует запуска `npx playwright test --list` и сопоставления спеков). Известно: `admin-reports` имеет e2e в `tests/e2e-archive/`, `pile-journal` — нет.
2. **Интеграционные тесты** загрузки данных (API моки) — только unit-тесты Vitest. Vitest не загружает `.env`, интеграционные спеки могут silently skip.
3. **Производительность** рендера больших таблиц (`pile-journal` 17 колонок, `admin-reports` сортировка 1000+ строк) — не измерялась.
4. **Актуальность комментариев** в коде — не верифицирована против текущего поведения (многие комментарии ссылаются на F-RXXX номера задач).
5. **Связи с `operator-mobile`** — `run-inspection.tsx` использует `useLocalFormDraft` из `operator-mobile/`, но операторский модуль заморожен. Риск: изменение в `operator-mobile` сломает инспекции.
