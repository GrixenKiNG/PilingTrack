# N1021-G16 — Обработка ошибок БД в маршрутах API

## Итог

Проверено **84 маршрута** в `src/app/api/**`. Большинство (81) используют общие обёртки `withApi` / `withMutation` из `src/core/api-wrapper.ts` и делегируют обработку ошибок Prisma туда. Найдено **4 маршрута** с ручной обработкой ошибок БД, которые дублируют или расходятся с логикой обёртки:

| # | Маршрут | Проблема | Серьёзность |
|---|---------|----------|-------------|
| 1 | `reports/delete` | Ручной парсинг сообщения ошибки Prisma P2025 вместо кода | **критично** |
| 2 | `reports/pdf` (download job) | Проверка строки `'not-found'` в сообщении ошибки | **важно** |
| 3 | `reports/single-pdf` (download job) | Аналогичная проверка строки `'not-found'` | **важно** |
| 4 | `orion/lead` | Весь блок `try/catch` отдаёт 500, не используя маппинг P2002/P2025 | **важно** |

Остальные маршруты либо используют обёртку корректно, либо (публичные эндпоинты) не работают с Prisma напрямую.

---

## Методика

1. **Поиск catch-блоков**: `rg "catch\s*\(" src/app/api --type ts` — 100+ вхождений.
2. **Фильтрация**: оставлены только маршруты, где `catch` не просто делает `throw err` (делегирует в обёртку), а возвращает свой `NextResponse`.
3. **Поиск ручной работы с Prisma**: `rg "P20|PrismaClientKnownRequestError|message\.includes" src/app/api`.
4. **Сравнение с обёрткой**: прочитан `src/core/api-wrapper.ts:24-32,118-125` — маппинг `P2025→404`, `P2002→409`, остальное→500; сообщения — обобщённые («Запись не найдена», «Запись с такими данными уже существует»).
5. **Проверка каждого кандидата**: открыт файл, проанализирован `catch`-блок.

Исключены из проверки (frozen areas): `src/app/api/orion/**` (можно читать, не предлагать правки), `src/app/api/operator/**`.

```ts
const PRISMA_STATUS: Record<string, number> = {
  P2025: 404, // Record not found
  P2002: 409, // Unique constraint violation
};

// В catch-блоке обёртки (строки 118-125):
else if (isPrismaKnownError(error) && PRISMA_STATUS[error.code]) {
  logger.warn('API handler hit a Prisma constraint', { domain, code: error.code, message: error.message });
  response = NextResponse.json(
    { error: error.code === 'P2025'
      ? 'Запись не найдена — возможно, её уже удалили. Обновите страницу.'
      : 'Запись с такими данными уже существует' },
    { status: PRISMA_STATUS[error.code] }
  );
}
```
