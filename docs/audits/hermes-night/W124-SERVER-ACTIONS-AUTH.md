# W124 — Серверные действия без проверки входа

## Итог

- В `src/` **нет ни одной директивы `'use server'`** — ни в виде файла целиком, ни внутри функций: серверных действий в проекте нет вообще.
- Следовательно: **0 серверных действий**, **0 без проверки входа**, находок по теме — **0** (ни критичных, ни важных, ни мелочей).
- Это не «пропустил»: проверено перебором всех `.ts/.tsx` в `src/` (1345 файлов), независимым `grep` по всему рабочему дереву и по поисковым маркерам серверных действий (`useActionState`, `useFormState`, `formAction`).
- Единственная поверхность изменений данных — маршруты API (`src/app/api/**/route.ts`, 141 файл). AGENTS.md уже требует оборачивать их в `withApi`/`withMutation`; нарушения этой поверхности — тема других отчётов (например, W117 «Изменения данных без аудита»), не этого.
- **Самое важное:** риска «вызов действия по имени в обход маршрута» в этом коде нет — такой поверхности не существует. Повторять эту проверку при добавлении новых фич: появление `'use server'` создаст новую, никем не обёрнутую дверь.
- Побочно подтверждено: маршруты контура готовности (`readiness/**`), которые не используют `withMutation` по имени, на самом деле обёрнуты через `withReadinessCommand`, а тот внутри зовёт `withMutation` (`src/app/api/readiness/_shared/route-adapter.ts:17`) — то есть тоже защищены.

## Не проверено

- **Совпадение в собранном бандле.** `grep -i "use server"` даёт попадания в `.next/**` (vendor-чанки, fallback). Это строки из библиотек Next.js/Sentry, а не пользовательские действия; исходники `src/` чисты. Не разбирал содержимое чанков построчно — не проверено, что за строка.
- **Замороженные области.** `src/components/piling/operator-mobile/v7/*` и ORION не сканировал на предмет серверных действий отдельно (по AGENTS.md они заморожены и не трогаются). Их `action={...}` — пропсы компонентов, не `form action`; но полного чтения этих файлов не делал — не проверено.
- **Файлы вне `src/`.** `agents/`, `scripts/`, `tests/`, `e2e/` на `'use server'` не просматривал целенаправленно (grep по всему дереву дал ноль вне `src`, но отдельного построчного подтверждения по каждому каталогу нет) — не проверено.
- **Динамическая генерация.** Не проверял, не генерируются ли серверные действия кодогенерацией (например, из `prisma/generated` или скриптов сборки) — не проверено.
