## Итог

Проект не использует `prom-client` (в `package.json` нет зависимости — проверено `search_files`), весь экспорт метрик — рукописный текст в `src/app/api/metrics/route.ts` и трёх модулях `src/core/observability/**`. `alerts.yml` же написан частично под имена prom-client-дефолтов (`nodejs_heap_size_*`, `nodejs_gc_duration_seconds_sum`), которых приложение никогда не отдаёт, — эти правила физически не могут сработать.

Счёт по важности: **критично — 1, важно — 10, мелочь — 7** (всего 18).

Главное: причина нулей `backup_*` — не скрипт, а гейт `BACKUP_ENABLED`. Писатель ключей `system:backup:*` в репозитории есть (`scripts/backup-postgres.sh:151-153`, плюс legacy `scripts/backup.sh:95-97`), но `checkers/backup.ts:11-15,72-74` без `BACKUP_ENABLED=true` возвращает `source:'disabled'` без возраста и без `s3Synced`, и `route.ts:111-112` печатает жёсткие `0`/`0`. Переменной нет ни в одном `.env.example` (в т.ч. `.env.production.example`). Тот же гейт глушит алерт `OffsiteBackupNotSynced` (`alerts.yml:229`) — по умолчанию он не звенит никогда.

Второй класс мёртвых проверок — несовпадение имён: `OutboxBacklog` ждёт `outbox_events_pending_total`, приложение отдаёт `outbox_pending_count`; `HighMemoryUsage` и `HighGarbageCollectionTime` ждут prom-client-имена, приложение отдаёт `process_*`. Пять правил бизнес-логики (`reports_created_total`, `sync_*`) вообще не имеют источника нигде в `src/`.

Топ-5:
1. `backup_age_hours` / `backup_s3_synced` де-факто мёртвы (BACKUP_ENABLED не задан) → нет ни сигнала о бэкапах, ни алерта `OffsiteBackupNotSynced`.
2. `OutboxBacklog` (`alerts.yml:162`) ссылается на несуществующее имя `outbox_events_pending_total` — переполнение outbox не будет замечено.
3. `HighMemoryUsage` (`alerts.yml:106`) — `nodejs_heap_size_used_bytes`/`nodejs_heap_size_total_bytes` не отдаются никогда.
4. `NoReportsCreated` (`alerts.yml:142`) и `HighSyncFailureRate` (`alerts.yml:152`) — метрик `reports_created_total`, `sync_errors_total`, `sync_updates_total` нет в приложении.
5. `PostgresSlowQueries` (`alerts.yml:81`) — опечатка `pg_stat_statatments_mean_time_seconds` → правило не сработает.
