  Playwright в этой сессии недоступны. Расхождения «на одном экране X, на другом Y» — вывод из кода
  отрисовки и ветвлений; в рантайме не подтверждены.

  экран оператора берёт `knowledgeDoc.expiresAt` (`mobile-shift-query.ts:229`, `admission.ts:327-348`)

  не проверял — риском не подтверждено.
- **`documentExpiry` округляет вверх** (`document-expiry.ts:35-39`): `Math.ceil` для срока в прошлом меньше
  суток даёт `daysLeft=0` → статус `expiring`, не `expired`. Намеренно ли это «льготные сутки» — по коду не
  видно однозначно; как дефект не заявляю, требуется подтверждение владельца/теста.

  тенанта»; проверять частоту в бою нечем.
