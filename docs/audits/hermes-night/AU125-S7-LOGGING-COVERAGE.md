- Режим: только чтение, код приложения не изменялся

## Итог

Найдено **38** находок: **7 критично**, **17 важно**, **14 мелочь**.

Главное: **сквозной корреляции в логах нет вообще.** Слой трассировки (`src/lib/trace-context.ts`) написан, но `traceContext.run(...)` не вызывается нигде вне тестов — `getTraceId()` всегда возвращает `'no-trace'`, `getRequestIdFromContext()` всегда `undefined`. Из 301 вызова `logger.*` в `src/` ни один не передаёт `traceId`; только 4 передают `requestId`, 3 — `userId`, 9 — `tenantId`. Приложение также **не пишет access-лог**: `withApi` не журналирует ни успешный, ни отклонённый запрос (только метрики Prometheus), поэтому последовательность запросов при разборе инцидента по логам не восстанавливается. Отказ прав (`assertCan`/`assertRole`/CSRF/лимит попыток) не журналируется: `withApi` глушит `ServiceError` без записи (`src/core/api-wrapper.ts:108-112`), CSRF — 6 точек 403 без записи, 429 в `withMutation` — без записи. Причина недоступности БД/Redis в health-проверках и в `system-service` тоже не пишется — видно только «down».

Топ-5:
1. `traceId`/`correlationId` в логах нет: `src/lib/trace-context.ts:56` + `src/lib/request-context.ts:163` — `initTraceContext` не вызывается никем.
2. Нет access-лога запроса: `src/core/api-wrapper.ts:69-146`.
3. Отказ прав не журналируется: `src/services/auth/authorization-service.ts:162-181`, `src/core/api-wrapper.ts:108-112`.
4. `requireAuth` при сбое БД отдаёт 500 «Authentication failed» без записи и без Sentry: `src/lib/auth.ts:202-211`.
5. `requestId` звена цепочки аудита готовности отсоединён от HTTP-запроса: `src/modules/readiness/infrastructure/audit/append-audit.ts:46`.

Числа (все — из команд, см. «Методика»): вызовов `logger.*` в `src/` без тестов — **301** (`debug` 12, `info` 105, `warn` 73, `error` 111); по каталогам: workers 106, core 62, services 59, app 39, lib 21, modules 10, components 0. Маршрутов `route.ts` — **141**, обёрнуто `withApi`/`withMutation`/`withReadinessCommand` — **134**, из них импортируют `logger` — **18**. Блоков `catch` в `src/` без тестов — **675**; из них ничего не бросают и ничего не пишут — **306** (277 + 29 пустых), в серверной части (`core|services|modules|workers|lib|app`) — **70**.
