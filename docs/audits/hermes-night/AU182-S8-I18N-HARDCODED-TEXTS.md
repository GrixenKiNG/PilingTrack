Точный разбор строковых литералов (скрипт Node, не Python — его нет): обход `src/**/*.{ts,tsx}` минус тесты и замороженные зоны; снятие блочных `/* */` и строчных `//` комментариев; извлечение одинарных/двойных/шаблонных литералов по регулярному выражению; фильтр «есть кириллица и длина ≥ 3»; нормализация пробелов; группировка по тексту с подсчётом числа файлов.
