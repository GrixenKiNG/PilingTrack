  3. **Сортировки нет.** Порядок жёстко задан `orderBy: { date: 'desc' }` (`report-query.service.ts:161`), заголовки колонок — статичные `<span>`, не кликабельны (`admin-reports.tsx:391-398`). Отсортировать по оператору/объекту/сваям или по возрастанию даты нельзя.
  4. **Курсорная пагинация по неуникальному ключу.** `paginateQuery` листает `cursor: { id }` при `orderBy: { date: 'desc' }` (`report-query.service.ts:154-163`, `src/lib/pagination.ts:44-53`). У отчётов за один день порядок внутри даты недетерминирован (нет тай-брейкера `id`), поэтому при «Загрузить ещё» строка может **повториться или потеряться** между страницами.

При отборе больше 100 отчётов показанный отфильтрованный список молча неполон; предупреждения об этом нет.
