## Что видит человек: сценарий за сценарием

Тексты дословно; источник — файл:строка.

### 1. Открыть редактор и загрузить шаблон

- Либо плавающая кнопка «Редактировать шаблон» (`layout-editor.tsx:86-88`), либо режим окна (`autoOpen`, `:64-67`).
- **Успех.** Шапка: `title`, кнопки «Отменить» / «Повторить» / «Предпросмотр» / «Сбросить» / «Сохранить шаблон» / «Блоки» и «Свойства» (на телефоне) / «Закрыть» (`:153-160`). Пустой список — «Редактор шаблона плитки» в `aria-label` (`:148`).
- **Сбой загрузки (500/обрыв/не-ok).** Сообщения нет: `loadTemplate` глотает `catch` и игнорирует `!res.ok`, редактор открывается со стандартным шаблоном (`use-layout-template.ts:69-87`; в постраничном — `use-page-layout-template.ts:61-71`). Отличить «уже настроено и не прочиталось» от «ещё не настраивали» невозможно (находка 1).
- **Неизвестная поверхность (404)** и **400 «Не задан контекст организации»** до редактора не доходят: id поверхностей заданы в коде (`surfaces.ts:55-80`), а не из URL (находка 1, сноска).

### 2. Двигать/добавлять/удалять блоки

- **Успех.** Блоки двигаются мышью и стрелками (`layout-canvas.tsx:33-57`); «Добавить текст» / «Добавить разделитель» / «Добавить фото» / блоки данных (`layout-block-library.tsx:30-54`).
- **Удаление блока данных** — `window.confirm('Удалить блок данных из шаблона? Его можно вернуть из библиотеки.')` (`layout-editor.tsx:142`); текст/разделитель/фото удаляются сразу, без вопроса (`:140-145`, находка 14).
- **Ошибка загрузки фото** — текст исключения как есть, в блоке слева: `setImageError(error.message)` (`:105-107`), показ в `layout-block-library.tsx:48`. При обрыве — «Failed to fetch»; при отказе пресайна — «Не удалось начать загрузку (500)» (`equipment-photo-upload.ts:23`) (находка 8).

### 3. Сохранить шаблон

- **Успех.** Полноэкранный редактор закрывается, правок в тосте нет (`use-layout-template.ts:136-137`); постраничный остаётся открытым и режим правки гасится (`use-page-layout-template.ts:92-93`). Состояния «сохраняется» нет (находка 7).
- **403 (в т.ч. CSRF).** «Только администратор может сохранять шаблон» (`use-layout-template.ts:133`; постранично — «…сохранять раскладку», `use-page-layout-template.ts:89`) — для CSRF-403 это неверная причина (находка 3).
- **400/5xx/404/401.** Всё, кроме 403, сводится к «Не удалось сохранить шаблон» / «Не удалось сохранить раскладку»: тело `{error}` сервера не читается, статус не различается (`use-layout-template.ts:132-135`; сервер отдаёт «Некорректные данные» на `TypeError` — `route.ts:73`) (находка 6).
- **Обрыв сети.** Тихо: `authFetch` бросает, обработчика нет (находка 4).

### 4. Сбросить

- «Сбросить» (`layout-editor.tsx:156`; `page-layout-editor.tsx:41-47`) → `DELETE /api/layout/[surfaceId]` (`use-layout-template.ts:140-151`; `use-page-layout-template.ts:96-105`). **Подтверждения нет** — сохранённая раскладка удаляется сразу, черновик теряется (находки 5, 15).
- Успех: ни тоста, ни пояснения, что вернулись к стандарту; в полноэкранном редакторе шаблон просто перерисовывается (`use-layout-template.ts:147-150`).
- **403/5xx** — «Только администратор может сбросить шаблон» / «Не удалось сбросить шаблон» (`:145`); **обрыв** — тихо (находка 4).

### 5. Закрыть редактор

- «Закрыть» спрашивает `window.confirm('Отменить несохранённые изменения?')`, но только если `dirty` (`layout-editor.tsx:123-125`).
- **Уход в обход кнопки.** Смена области в шапке (`equipment-card-grid.tsx:75-85` → `onSwitch` → новый `key={editScope}` `:198`) перемонтирует редактор и выбрасывает черновик без вопроса; смена дашборда/вкладки в Настройках разбирает `PageLayoutEditor` и теряет правку так же (`workspace-settings.tsx:381-390`); закрытие/перезагрузка вкладки браузера не перехватываются (`beforeunload` нет) (находка 2).
