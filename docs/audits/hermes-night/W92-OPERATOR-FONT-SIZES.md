## Не проверено

- **Приложение не запускал, браузером не мерил.** Все размеры — расчёт из классов Tailwind и токенов `operator-type.css:17-35` и `globals.css:77-82`; `getBoundingClientRect` на 375 px не снимал, расхождение ±2 px возможно.
- **Находка №1 (шкала не подключается на `/operator/next`)** — вывод из графа импортов (`operator-type.css` импортируют ровно два модуля), а не из живого рендера. Проверял только текстовым поиском по `operator-type` в `src/`; фактически собранный CSS маршрута не инспектировал. Нужен либо `npm run build` с просмотром CSS-чанка, либо Playwright с системным Chrome.
- **Порталы** (`ui/dialog`, `ui/sheet`) на наличие/отсутствие корневого класса в дереве не проверял — в самой области оператора модалок не нашёл, вывод из прошлого аудита R79 (№34) не переносил на этот случай автоматически.
- **Контраст** (`text-muted-foreground`) численно по WCAG не измерял; `--muted-foreground` на живом экране переопределён в `operator-type.css:29` (0.4 вместо 0.5), но замеров нет.
- **Читаемость «в перчатке на солнце»** — качественная оценка, не измерение. Задача — опись размеров, не тест.
