# QW01–QW10: как читать отчёты аудита Qwen

Отчёты `QW*` написала локальная модель Qwen3.8 (Hermes, 11.10.2026), без запуска приложения и тестов. Это список мест для внимания, а не готовые выводы. Часть находок помечена в самих отчётах «по записям сеанса» — модель не перечитала файл. Такие пункты принимать только после проверки по коду.

## Выборочная проверка Claude (11.10.2026)

| Отчёт | Находка | Итог |
|---|---|---|
| QW02 F1 | `decrypt()` возвращает значение без префикса `enc:` как есть (`src/core/security/encryption.ts:155-159`) | подтверждено |
| QW02 F2 | HSTS нет в `src/proxy.ts` | по замыслу: HSTS задан в Caddy (`deploy/Caddyfile.prod:30`), `next.config.ts` это объясняет; важность завышена |
