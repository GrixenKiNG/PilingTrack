# R126 — админка на телефоне (ширина 375 px)

Только чтение: ни один существующий файл не изменён. Область — админ-оболочка (`/admin/**`,
`/monitoring`, `/inspections`, `/admin/to`, `/admin/safety`). Операторские варианты (`operator*`) и

(Playwright 1.63 + системный Chrome, вход `admin@piling.ru`), не только по коду.

## Итог

- Всего находок: **18** — критично **3**, важно **9**, мелочь **6**. Плюс приложение со списком широких таблиц (path:line).
- **Горизонтальная прокрутка страницы** на 375 px найдена ровно на одном экране — **`/admin/maintenance`**: документ расширяется до **503 px** (замерено). Причина — строка пагинации.
- **Обрезание содержимого без прокрутки** — на дашборде **`/admin`**, секция «Парк установок»: плитки 373 px внутри секции 341 px (`overflow-hidden`), обрезается **бейдж статуса** установки («Требует ТО», «Ждём отчёт»).
- **Диалоги выше экрана**: при высоте 375×568 и 375×500 диалоги без ограничения высоты обрезаются сверху и снизу, и **крестик закрытия уходит за экран** (проверено: «Редактировать объект», «Новый пользователь», «Добавить элемент»). У диалогов с `max-h-[90vh]` проблемы нет.
- **Мелкий шрифт** 10–11 px массово подтверждён на `/admin/reports` (11 px ×508 мест), `/monitoring` (10 px ×59, 11 px ×84), `/admin/analytics` (11 px ×10) — это **повтор R79**.
- **Широкие таблицы** (`min-w-[1050px]` и больше) страницу не ломают — у всех есть локальная `overflow-x-auto`; но на телефоне их надо возить вбок, решающие колонки («Действия», «Решение») за кадром — **повтор 22**.
- Уведомления (`feedback-center.tsx`) больше **не** уезжают за край: ширина исправлена на `w-full … sm:w-[440px]` (было критично в отчёте 22, №1) — проверено в коде.
- Самый важный пункт — **№1**: `/admin/maintenance` ломает ширину страницы (503 px при 375), то есть «горизонтальная прокрутка страницы» из условия задачи реально существует на одном экране.

## Методика

Повторяемо (root — рабочий каталог ветки `hermes/q4-0926`):

1. Прочитал `AGENTS.md` (модель доверия, замороженные зоны `operator*`/ORION, «выглядит мёртвым, но должно остаться»). Замороженное не трогал.
2. Прочитал предыдущие отчёты по теме, чтобы не выдавать известное за новое: `22-phone-layout.md`, `R79-small-text-admin.md`, `R73-mobile-targets-sweep.md`, `54-mobile-targets.md`. Найденное там в таблице помечено «повтор».
3. `curl` подтвердил, что `localhost:3000` отвечает 200 → перешёл к браузерному замеру.
4. Браузерный замер (Playwright из `node_modules`, канал `chrome` = системный Chrome; временные скрипты лежали в скретч-каталоге Hermes, не в репозитории). Вход — `#email`/`#password`, кнопка «Войти» (как в `e2e/page-objects/login.page.ts`). Для каждого маршрута снимал через `page.evaluate`:
   - `document.documentElement.scrollWidth` против `window.innerWidth` → **горизонтальная прокрутка страницы**;
   - `getBoundingClientRect()` всех видимых элементов с `right > innerWidth` + ближайший предок со `overflow-x` в `auto/scroll/hidden/clip` → обрезано или прокручивается;
   - `scrollWidth > clientWidth` при `overflow: hidden/clip` → **обрезано без прокрутки**;
   - размеры `min-w-[…]` и `table`;
   - распределение `font-size ≤ 13px` по видимым текстовым листьям.
   Прогоны: `375×812` (iPhone), `375×667` (SE2), `375×568` (SE1), `375×500` (с открытой клавиатурой/ландшафт) — ширина везде 375, как в задаче. Отдельно открывал диалоги и мерил их `rect` (высота, `top`, `bottom`, выход за экран, положение крестика).
5. Маршруты: `/admin`, `/admin/equipment`, `/admin/reports`, `/admin/analytics`, `/admin/settings`, `/admin/sites`, `/admin/crews`, `/admin/users`, `/admin/dictionaries`, `/admin/maintenance`, `/admin/to`, `/admin/safety`, `/admin/checklists`, `/admin/incidents`, `/admin/piles` (`?view=piles`), `/monitoring`, `/inspections`.
6. Каждую находку открывал в коде и читал в контексте (`read_file`); строки в таблице — из этих чтений. Широкие таблицы перечислены грепом `min-w-\[[0-9]+px\]` по `src/components/piling`.

Ограничения: замер — headless Chrome, шрифты и переносы в реальном браузере владельца могут дать ±2 px; «частота в поле» — оценка по ролям, не по статистике (её нет).
