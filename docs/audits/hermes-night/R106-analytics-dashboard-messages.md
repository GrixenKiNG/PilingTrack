## Что видит роль: сценарий за сценарием

Тексты дословно; источник — файл:строка.

### 1. Открыть «Аналитику»

Успех: заголовок «Аналитика» + подпись «Производительность операторов и тренды по объектам» (`admin-analytics.tsx:221-227`), полоса KPI-плиток (`:237-255`), ниже — вкладки. Экран тянет **четыре независимых источника**: `/api/sites/all`, `/api/monitoring/fleet`, `/api/admin/analytics/overview` и, по вкладке, тренд/KPI.

- **403.** Приходит как обычный не-ok. Список объектов: `setSitesError('Список объектов временно недоступен.')` (`:80,83`); парк: `setFleetError('Показатели парка временно недоступны.')` (`:93,99`); сводка за период: `setOverviewError('Не удалось загрузить аналитику за период.')` (`:117`). Ни один текст не говорит про права. Серверный текст — «Доступ запрещён» (`authorization-service.ts:164`). Достижимо: администратор в режиме «Действую как OPERATOR» проходит серверный гвард раскладки (он по своей роли, `require-page-ability.ts:9`), запрос уходит с `x-acting-as` (`api.ts:20-23`) и `assertCan` отвечает 403.
- **5xx.** Те же тексты (`:80,93,117,158`). Отдельного текста для 500 нет.
- **Обрыв сети.** Сводка: «Сеть недоступна. Проверьте соединение и повторите.» (`:120`). А парк/объекты при обрыве дают те же «временно недоступен» (`:83,99`).
- **Пусто.** Плитки считаются из нулей, есть отдельные пустые тексты в блоках (см. ниже). Общий «пустой период» — `EmptyState` «За выбранный период нет отчётов. Измените период или объект в фильтрах выше.» (`:265-267`).
- **401.** `authFetch` делает logout в store (`api.ts:66-68`), раскладка уводит на `/login` (`layout.tsx:341`). Сообщения об истечении сессии нет.

### 2. Вкладка «Операторы»

- Успех: таблица «Топ-10 по забитым сваям» (`:345-389`), по умолчанию 5 строк, «Показано 5 из N операторов» + «Смотреть всех» (`:382-385`). Заголовок обещает 10, показано 5 — уже R35 №22, здесь не считается новым.
- **403/5xx** сводки: сверху баннер `QueryErrorBanner` (`:258-259`), но сама вкладка при этом рисует `EmptyState` «За выбранный период нет данных по операторам» (`:339-340`) — «не загрузилось» выглядит как «данных нет». **Уже отмечено R16 №12.**
- **Пусто** (сводка пришла, операторов нет): тот же `EmptyState` — здесь текст уместен.

### 3. Вкладка «Тренды по объектам» + выбор объекта

- Успех: диаграмма «Тренд за месяц», недели по 4 бакета (`:129-135,406-442`).
- Выбор объекта — пилюли `[{id:'all',name:'Все объекты'}, ...sites]` (`:413`); берутся из `/api/sites/all`. Если он отказал, остаётся только «Все объекты», а объяснение — лишь в верхнем баннере (`:231-235`), у самой панели — нет.
- **403/5xx:** `setTrendsError('Не удалось загрузить тренды по объектам.')` (`:138`) → баннер с «Повторить» (`:399-400`). Про права — ни слова.
- **Обрыв:** «Сеть недоступна. Проверьте соединение и повторите.» (`:141`).
- **Пусто:** `EmptyState` «Нет данных по неделям. Проекция SiteWeeklyTrend заполняется автоматически по мере поступления отчётов.» (`:404`) — имя внутренней модели БД в пользовательском тексте; «Повторить» нет.

### 4. Вкладка «Надёжность ТО»

- Успех: плитка `MaintenanceSummaryTile` (`:458-459`) + «Топ проблемных установок» (`:461-491`).
- **403 — достижимо законно.** `analytics.read` есть у FOREMAN (`authorization-service.ts:63`), поэтому страница и вкладка ему открыты; но `/api/maintenance/kpi` требует `maintenance.manage` (`maintenance/kpi/route.ts:45`), которого у FOREMAN нет (`authorization-service.ts:108`) → 403 → `setKpiError('Не удалось загрузить показатели техготовности.')` (`:158`). Вкладка при этом не скрыта и не объяснена.
- **5xx/обрыв:** тот же текст (`:158`) / «Сеть недоступна. Проверьте соединение и повторите.» (`:161`).
- **Пусто:** «Нет данных ТО за период.» (`:454`), «Отказов за период не зафиксировано.» (`:468`).

### 5. Настройка раскладки — «Настройки → Шаблоны плиток» (админ)

`AnalyticsDashboardLayoutEditor` (`kpi-widgets.tsx:139-181`) через `PageLayoutEditor` (`layout-editor/page-layout-editor.tsx`).

- Загрузка раскладки: `GET /api/layout/analytics-dashboard` (`use-page-layout-template.ts:56,64`). Любой сбой **молча** (`catch {}`, `:66-68`) → шаблон по умолчанию.
- Предпросмотр: тянет `/api/monitoring/fleet` и `/api/sites/all` (`kpi-widgets.tsx:147-150`); при отказе любого — `setData(null)` (`:166-168`), и плитки рисуются из нулей (`:174-177`): «Установок 0», «Объектов 0».
- Сохранить: `PUT /api/layout/[surfaceId]` (`:83`). Не-ok → тост: 403 → «Только администратор может сохранять раскладку», прочее → «Не удалось сохранить раскладку» (`:88-91`). Обрыв — исключение без обработки (тоста нет).
- Сбросить: `DELETE` (`:97`). Тот же разбор (`:98-101`). Диалога подтверждения нет.
- Успех сохранения/сброса пользователю никак не сообщается (`:92-93,102-105`).
