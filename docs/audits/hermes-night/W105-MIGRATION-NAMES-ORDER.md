Скрипт-разбор жил в scratch-каталоге Hermes (в репозиторий не добавлялся).

1. Перечень папок: `ls -d prisma/migrations/*/` → **107** (`migration_lock.toml` исключён как не-папка).
2. Проверка состава: для каждой папки `ls "$d"` — ровно `migration.sql`, посторонних файлов не найдено.
3. Проверка формата имени: регулярное выражение `^\d{14}_[A-Za-z0-9_]+$`. Дополнительно каждая метка
   разложена на `YYYY/MM/DD/HH/MM/SS` и сверена с реальной датой через `Date.UTC` — так найдены
   метки с несуществующим временем (минута ≥ 60), которые по «14 цифрам» формально проходят.
4. Проверка порядка: список отсортирован лексикографически (для 14-значных имён это совпадает с числовой
   сортировкой); искалось первое место, где метка текущей миграции меньше предыдущей. Не найдено.
5. Дубли меток: группировка по первым 14 цифрам; выведены группы с ≥ 2 элементами.
6. Похожие описания: описания токенизированы по `[_\W]+`, для всех пар посчитан коэффициент Жаккара
   по множествам слов; пары с ≥ 0,5 вынесены на ручную проверку. Соседние/подозрительные пары прочитаны
   целиком (`head`/`sed` по `migration.sql`) — чтобы по тексту отличить «случайный повтор» от
   «серии одной фичи».
7. Ничего не выполнялось и не менялось: `prisma migrate *`, `prisma db push`, `db:generate` не запускались,
   БД и Redis не затрагивались, `.env` не открывался. Проверки — только по именам папок и тексту SQL.
