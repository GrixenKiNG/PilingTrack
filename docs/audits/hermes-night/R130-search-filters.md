# R130 — Поиск и фильтры: техника, пользователи, объекты, отчёты

Область: списки «Установки» (техника), «Пользователи», «Объекты», «Отчёты» (смены + журнал забивки + история отчётов), плюс смежные поиски (справочники, чек-листы, журналы техготовности), где видна та же болезнь. Операторские экраны и ORION не читались.

## Итог

- Всего находок: 17. По важности: **важно — 5**, **мелочь — 12**, критично — 0.
- **Одна и та же причина у 5 списков: поиск не нормализует «ё/е» и не схлопывает лишние пробелы.** Поиск по «Петр» не находит «Пётр» ни в пользователях, ни в справочниках, ни в журналах техготовности (в справочнике кода уже есть правильный образец `.replace(/ё/g,'е')`, но он не переиспользован).
- **Свободного текстового поиска нет в трёх из четырёх списков:** в «Установках», «Объектах» и «Отчётах» есть только выпадающие/быстрые фильтры — найти установку по «LRH 100» или объект по «Солнечный» текстом нельзя.
- **Фильтр не сохраняется при возврате в трёх из четырёх списков:** в адресе живёт только фильтр «Пользователей» (`?filter=&q=&userId=`) и вкладка «Отчётов»; установки/объекты/отчёты/журнал/история теряют отбор при перезагрузке, «Назад» и переходе по ссылке.
- **Топ-5:** №1 (ё/е), №2 (нет поиска в технике), №3 (нет поиска в объектах), №4 (нет поиска в отчётах), №5 (отбор не в адресе).
- Мелочи: сброс фильтров спрятан в пустое состояние; нет кнопки «очистить» в поиске; подсказка «Ctrl + K» без обработчика; подсказки пустого состояния врут при честно пустом списке; в выборе операторов на объекте поиска нет.
