- Строки 1–8 — импорты 1–4 слов «стоят» внутри двойных кавычек: это исходники-заготовки, которые тесты подают на вход собственным парсерам (`handlers`, `staticSpecifiers`, `findGlobalDbInTx`). Проверяются сами парсеры, а не файловая система; соответствующих файлов в репозитории и не должно быть.
- Строка 9 — тип-импорт из генерируемого Prisma-клиента. Прямого `export … Prisma` в `client.js` нет, но тип разрешается через `client.d.ts → ./index`, поэтому `tsc --noEmit` чист. Правки не требуются (и `src/generated/**` — генерируемое, править нельзя, см. AGENTS.md §1).
