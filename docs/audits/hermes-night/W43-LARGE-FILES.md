## Методика

Что и как искалось (проверяемо повторно):

1. **Список файлов ветки.** `git diff --name-only main...HEAD -- src`, затем отфильтрованы тесты (`__tests__/`, `*.test.*`). Осталось 44 файла. База — merge-base ветки `main...HEAD` = `9f63f92d5ede3c4a7c1929d590cad6d6295a9af1`.
2. **Строки до/после.** После — `wc -l < <файл>`; до — `git show main:<файл> | wc -l` (как предписано задачей). Дополнительно проверено `git show $(git merge-base main HEAD):<файл> | wc -l`: **для всех 9 файлов совпадает с main tip**, поэтому расхождение «main tip vs merge-base» на результат не влияет.
3. **Что добавила ветка.** `git diff main...HEAD -- <файл>` и `git diff --numstat main...HEAD -- <файл>`; журнал — `git log --oneline main..HEAD -- <файл>`.
4. **Границы ответственности (швы).** Чтение файлов целиком (`read_file`) и разметка границ: `grep -nE '^(export )?(async )?function |^const [A-Z]'` + поиск баннеров `// ====` в монолитах.
5. **Покрытие тестами.** `grep -rl` по `src/` и `e2e/` по имени файла/символа.
6. **Проверка, что порог 500 никто не перешёл:** сравнение было/стало по всем 44 файлам (сортировка по «стало»).

Ограничение метода: «было» снято по **текущему** `main`, а не по merge-base (так предписано задачей). Для этих 9 файлов значения совпали, но при повторе на другой ветке расхождение возможно.
