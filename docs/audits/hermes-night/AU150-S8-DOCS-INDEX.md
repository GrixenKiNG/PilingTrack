## Итог (резюме для владельца)

Документации в репозитории много и она в основном честная: широкая часть помечает себя как заменённую/архивную. Всего под `docs/**` — 744 файла, из них 668 `.md`.
Главная проблема — не количество, а **устаревшие ссылки «файл:строка» без обновления после рефакторингов**: `docs/pile-journal.md` целиком ссылается на `pile-passport.service.ts`, который теперь фасад на 76 строк; ни одна из 9+ цитируемых строк там не существует.
Второе — **расходящиеся ключевые числа в трёх документах об одном и том же** (граф GitNexus): `docs/DATA-SOURCES.md` ≠ `.gitnexus/meta.json` ≠ `AGENTS.md`.
Третье — **индекс ADR (`docs/adr/README.md`) перечисляет 8 решений, а в папке их 19**.
Четвёртое — два «живых» руководства (`docs/dev-workflow.md`, `docs/dev-modes.md`) описывают удалённый 26.09.2026 сервис `ws`; `docs/onboarding-orion-app.md` говорит о «четырёх ролях», в схеме их семь.
Находок по уровням: **критично — 0, важно — 6, мелочь — 12**. Отдельных «errors» уровня «критично» не выявлено: устаревшие документы не влияют на рантайм, но вводят в заблуждение агентов/ревьюеров, которые идут по их ссылкам.
