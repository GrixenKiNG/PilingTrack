## Методика

Что искал и чем (все команды — из корня `D:/PillingR/wt-night-code`, PowerShell, отдельным запуском):

1. **Список файлов >500 строк.** `git ls-files src` + подсчёт строк по каждому файлу в `node` (`s.match(/\n/g).length`), фильтр `generated|\.test\.|\.spec\.|__tests__`. Замечание: PowerShell `Measure-Object -Line` **пропускает пустые строки** и даёт заниженное число (для `rate-limiter.ts` — 445 вместо 506), поэтому счёт вёлся в `node` по числу `\n`. Сверка с заданием: `rate-limiter.ts` = 506, `audit-service.ts` = 1036 — совпало.
2. **Число импортёров.** Скан всех `src/e2e/tests/scripts/*.ts(x)`: сбор спецификаторов из `from '...'`, `import('...')`, `require('...')`; совпадение по хвосту пути (2 сегмента каталога + имя или имя `index`-файла). Плюс контрольные прогоны `git grep -l -F <путь>` и `git grep -n -E "<Имя>"`. Точные числа — в таблице; мелкие расхождения относительных импортов отмечены в тексте.
3. **Структура файла.** Для каждого файла: строки верхнего уровня (`export|function|const|interface|type|enum`), блок с максимальным телом (баланс `{}`), число хуков (`useState|useEffect|useMemo|useCallback|useRef|useReducer`).
4. **Чтение.** Ключевые участки каждого файла из разбора открыты напрямую (в таблице — `путь:строка` по `Read`); замороженные файлы не читались построчно, только перечислены.
5. **Тесты.** `git ls-files src` с фильтром `*.test|*.spec` по каталогам; плюс поиск импорта каждого модуля тестами.
6. Замороженные зоны определял по AGENTS.md §1 (экраны оператора `src/app/operator/**`, `src/app/(app)/operator/**`, `src/components/piling/operator*/**`, `src/modules/operator-mobile/**`) и ORION (`src/components/orion/**`); плюс явный список «выглядит мёртвым, но нужен» (`operator-dashboard.tsx`).

Шкала серьёзности (по реальному сценарию): **критично** — размер сам по себе не дефект ни в одном файле, поэтому 0; **важно** — смешаны ≥3 обязанности (логика+правила+разметка/данные) в одном крупном блоке, при правке легко задеть чужую обязанность; **мелочь** — крупный размер оправдан (каталог/набор функций/уже делегирующий хаб) либо польза разделения ниже риска.
