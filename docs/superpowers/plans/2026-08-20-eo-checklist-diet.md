# Сокращение ежесменного осмотра до 3–5 минут

**Цель.** Предсменный осмотр (ЕО) занимает у оператора 3–5 минут, послесменный — до
минуты. Не «выглядит короче», а измеримо укладывается в это время.

**Кто решает.** Состав чек-листа — инженерное решение механика и владельца. Ниже —
предложение с расчётом и разметкой; вычёркивать строки из ежесменного осмотра без
подписи механика нельзя.

---

## 2. Шесть правил сокращения

Каждое правило — с примерами из действующих шаблонов.

### Правило 1. Один взгляд — одна строка

Оператор не проверяет «трещины корпуса», «деформации», «сварные швы», «проушины»,
«кожухи», «знаки безопасности» шестью отдельными действиями. Он один раз обходит молот.

- Молот, «Внешний осмотр»: **8 → 2** («Обход молота: корпус, швы, крепёж, кожухи» +
  «Нет течей гидромасла»).
- Машина, «Осмотр машины»: **6 → 2** («Обход машины: металлоконструкции, таблички,
  очистка» + «Огнетушитель и аптечка на месте»).
- Молот, «Гидросистема»: **6 → 2** (шланги и подтёки — одна строка; вибрация напорной и
  сливной линии — одна).
- Молот, «Гидроаккумуляторы»: **4 → 1** (корпус, крепления, утечки азота — один взгляд).
- Молот, «Ударная часть»: **6 → 2**.

Это самый крупный рычаг: около сорока строк «посмотреть и убедиться» сворачиваются в
восемь-десять.

**Что не сворачиваем:** строки, у которых разный ответ означает разные действия.
«Аварийный стоп» и «блокировка рычагов» обе про безопасность, но отказ первой
останавливает работу, а второй — нет.

### Правило 2. Уровни — одной строкой, а не четырьмя числами

«Уровень моторного масла», «ОЖ», «гидромасла», «топлива» — четыре ввода числа (около
50 секунд) там, где оператор смотрит четыре смотровых стекла подряд.

**Стало:** «Уровни (масло, ОЖ, гидравлика, топливо) в норме» — да/нет. Норму долива
оставляем в подсказке к строке.

**Решение владельца:** нужен ли остаток топлива числом для планирования заправки. Если
да — одна строка с числом вместо четырёх.

### Правило 3. Приборы говорят сами

«Температура масла на экране», «Давление масла двигателя», «Индикатор воздушного
фильтра», «Индикаторы возвратных фильтров» — это лампы и цифры на панели.

**Стало:** «Приборы: аварийных индикаций нет» — да/нет. **4 → 1.**

### Правило 4. Периодическое — в ТО-1, а не в ЕО

Проверки, которые сами руководства назначают реже смены, из ЕО убираем в ТО-1:

| Пункт | Где сейчас | Почему не ежесменно |
|---|---|---|
| Натяжение цепей (мерной рейкой) | ЕО базы | Руководство PVE 50PR — еженедельно |
| Давление зарядки гидроаккумуляторов (азот) | ЕО молота | Замер под давлением, не ежедневная операция |
| Демпферная подушка (высота) | ЕО молота | Износ идёт неделями; замена при < 20 % |
| Ход наголовника | ЕО молота | То же |
| Уровни масла в редукторах лебёдок | ЕО базы | Руководство — еженедельно |

Пять пунктов, четыре из них с вводом числа: около минуты в каждую смену впустую.

### Правило 5. Смазка — по карте, одной отметкой

«Смазка» в шаблоне молота — пять отдельных отметок (направляющие корпуса, направляющие
ударной части, наголовник, пальцы, подвижные элементы). Карта смазки уже показывается на
экране осмотра.

**Стало:** «Смазка по карте выполнена» — одна отметка. **5 → 1.** То же для вращателя.

### Правило 6. Убрать то, что не относится к началу смены

- «Проверка перед забивкой» (6 пунктов) — правило на каждую сваю, а не на смену. Место ему
  в инструкции, не в предсменном чек-листе. Две строки, критичные для безопасности
  («персонал выведен из опасной зоны», «транспортировочный фиксатор убран»), оставляем.
- «Зафиксирована наработка» дублируется дважды (база и молот), а моточасы приложение и так
  снимает отдельным шагом смены. Убрать из чек-листа.
- «Нет течей» есть и в базе, и в молоте — оставить одну строку.

## 4. Порядок работ

1. **Механик размечает.** Распечатать текущие списки по каждому шаблону и напротив каждой
   строки поставить: «оставить» / «объединить с №…» / «в ТО-1» / «убрать». Без этой
   разметки дальше не идём.
   → проверка: размечены все шаблоны уровня ЕО.

2. **Правка шаблонов** в разделе «Чек-листы» (`/admin/checklists`) — руками, редактором,
   который уже есть. Программировать ничего не нужно.
   → проверка: у каждой машины предсменная половина ≤ 30 пунктов, из них не более двух с
   вводом числа.

3. **Перенос в ТО-1.** Строки из правила 4 добавить в шаблоны уровня ТО-1 того же блока,
   чтобы требование руководства не пропало, а сменило периодичность.
   → проверка: каждая убранная из ЕО строка нашлась в ТО-1.

4. **Удалить мёртвый шаблон** «ЕО гидромолота» (5 пунктов, применимость к модели `HHK7A`,
   такой техники в парке нет — он никогда не собирается).
   → проверка: осмотров с этим шаблоном нет, значит удаление безопасно.

5. **Замер на живой смене.** Через две недели работы посмотреть медиану времени
   «создание → подпись» и долю осмотров, где все ответы «в норме».
   → критерий: медиана 3–5 минут. Меньше двух — список стал формальностью и режем слишком
   глубоко; больше семи — режем дальше.

**Запрос для замера:**

```sql
SELECT count(*) AS осмотров,
       round(percentile_cont(0.5) WITHIN GROUP (
         ORDER BY EXTRACT(EPOCH FROM ("signedAt" - "createdAt")) / 60)::numeric, 1) AS медиана_минут,
       round(100.0 * count(*) FILTER (WHERE "healthScore" = 100) / count(*), 0) AS процент_всё_в_норме
FROM "Inspection"
WHERE level = 'EO' AND status = 'COMPLETED' AND phase = 'PRE_SHIFT'
  AND "signedAt" > now() - interval '14 days';
```

## 5. Чего не делаем

- **Не трогаем подписанные осмотры.** `Inspection.templateSnapshot` хранит состав на момент
  подписи: правка шаблона историю не меняет и не портит.
- **Не выбрасываем требования руководств.** Периодическое переносим в ТО-1, а не удаляем.
  Требование, исчезнувшее из системы совсем, — это то, за что спросят при разборе
  происшествия.
- **Не режем безопасность ради секунд.** Аварийный стоп, ограничители, ЛЭП, ветер, опасная
  зона остаются отдельными строками, даже если рядом есть похожие.
- **Не заводим поле «периодичность»** в базе. Периодичность уже выражена уровнем
  (ЕО / ТО-1 / ТО-2 / ТО-3): перенос строки между шаблонами — это и есть смена
  периодичности. Новое поле дублировало бы существующий механизм.

## 6. Риски

- **Объединённая строка скрывает конкретику.** «Обход молота: корпус, швы, крепёж» при
  ответе «неисправно» не говорит, что именно. Лечится примечанием и фото — они и так
  требуются при этом ответе, и заведённый дефект попадает в журнал.
- **Оператор привыкнет к «всё в норме».** Отслеживаем долей осмотров со 100 % здоровья:
  если она месяцами выше 90 %, чек-лист снова стал формальностью — но уже коротким, и это
  повод пересматривать состав, а не длину.
- **Разметка ляжет на одного человека.** Несколько часов работы механика. Начать стоит с
  двух шаблонов: PVE 50PR (108 пунктов) и LRH 100 (91) — это четыре машины из девяти и
  худшие случаи.
