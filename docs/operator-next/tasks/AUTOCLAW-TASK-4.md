## C. Черновики переживают перезагрузку страницы

Телефон машиниста перезагружает страницу часто (сворачивание, экономия батареи). Храни черновики оболочки (выработка, паспорт, ответы осмотра, заметка закрытия) в `localStorage` с ключом по **пользователю и смене**; читать при старте смены, очищать по подтверждённой отправке и по явному «Очистить». Чужие черновики (другой пользователь на общем телефоне) не показывать и не отправлять. Если хранилище недоступно — работать как сейчас (в памяти) и честно показать «черновик не сохранится при перезагрузке». Текст «Осмотр сохранён на устройстве» оставляй только если он правда в `localStorage`. Тесты: перезагрузка (новый рендер оболочки) возвращает черновик своей смены; другой пользователь его не видит; после подтверждения черновика нет.
