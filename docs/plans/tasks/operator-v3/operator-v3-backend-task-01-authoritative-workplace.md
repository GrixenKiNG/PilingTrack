# Оператор v3 — серверное задание 01: достоверное рабочее место

Источник: `docs/plans/operator-v3-full-implementation.md`.

## Область работы

Реализовать достоверный серверный договор рабочего места из исходного плана. Задание ограничено серверной частью, программным интерфейсом и испытаниями; производственный пользовательский интерфейс не изменять.

## Точные файлы

- Точные файлы серверных маршрутов, служб и схем, перечисленные в исходном плане.
- Точные файлы целевых договорных и интеграционных испытаний, перечисленные в исходном плане.

Перед изменением определить точные пути и программные символы. В реализации запрещены временные пути и условные обозначения.

## Сначала испытание

Сначала добавить падающие испытания изоляции организаций и ролей, нормативной формы ответа, различия между явным отсутствием значения и отсутствующим полем, ответов с ошибками и запрета подмены достоверных фактов устаревшими резервными данными. Затем реализовать требуемое поведение и добавить регрессионное испытание полного ответа.

## Анализ влияния GitNexus

Перед изменением каждого программного символа выполнить `impact({target: "<точный символ>", direction: "upstream"})`. Зафиксировать прямых потребителей, затронутые процессы и уровень риска. При высоком или критическом риске предупредить и остановить изменение до проверки.

## Условия завершения

- Договорные испытания, проверка полномочий и изоляции организаций проходят.
- Достоверные факты нельзя незаметно заменить устаревшими резервными данными.
- Значение ошибок и явного отсутствия данных определено и проверено.
- Производственные файлы клиентского интерфейса не изменены.
- `detect_changes()` показывает только ожидаемые программные символы и процессы.

## Команды проверки

- `npm.cmd run test:contract -- <focused-tests>`
